# Retrospectives

A short look back after every working session ("run"), as part of the [self-improvement loop](../MASTER_PLAN.md#the-self-improvement-loop). Each one records what was delivered, what went well, what needs improving, and action items that feed [Next run](../NEXT_RUN.md). New lessons go into the repository's `CLAUDE.md`.

| Sprint | Dates | Summary |
|---|---|---|
| [Sprint 1](sprint-01.md) | 22–24 October 2026 | From an empty repository to release candidate 2: content, site, AI tutor, MCP server on npm, brand design, characters off everywhere |

For later sprints, copy the headings of the latest file and keep it short: summary and metrics, wins and challenges, issues with root causes, action items, lessons.
