# CantoLink Community Edition

**A free, open resource for learning spoken Cantonese — grammar patterns, topic vocabulary and self-marking practice. No account, no paywall.**

> 🚧 **Status: planning.** The product specification is ready for review; content and code are not yet published. Feedback is very welcome — please [open an issue](../../issues).

---

## Why this exists

Free Cantonese material is scattered, inconsistent and often teaches **written Chinese read aloud** rather than the Cantonese people actually speak (他是學生 instead of 佢係學生). Learners deserve a reference they can trust.

This project aims to be that reference, with one rule: **accuracy before breadth**. Every published example sentence is checked by a native speaker before it goes live.

## What it will include

| | |
|---|---|
| 📖 **Grammar pattern library** | 60 patterns (A1–B1) with plain-English explanations, 3–5 examples each, common mistakes and the written-Chinese equivalent where it differs |
| 🗂️ **Topic vocabulary** | ~360 words across 12 everyday topics — food, transport, shopping, health, work and more |
| ✍️ **Practice** | Flashcards, fill the gap, build the sentence, *spoken or written?* and tone drills, with built-in review of missed items |
| 🔤 **Romanisation-first** | Jyutping by default, Yale as a toggle; characters and English as optional overlays |
| 📴 **Works offline** | Installable web app; progress stays in your browser |

## Relationship to CantoLink

This is the free, open companion to [CantoLink](https://cantolink.org), an AI-powered Cantonese learning platform. The Community Edition covers reference content and drills; the paid product adds AI conversation practice and personalised learning paths.
